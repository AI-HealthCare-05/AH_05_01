# 입력·전처리·설명 범위

## 설명할 함수

`WaistCM.predict_waist_cm(frame, pregnancy_status='nonpregnant')`는 검증된 릴리스에서 `TuntunPredictor.waist`를 가져와 기존 `d0.prepare_features` 후 `waist.predict`를 실행합니다. 반환값은 행 순서에 대응하는 1차원 float64 배열, 단위 cm입니다. 이 수치는 실측값이 아니라 예측값입니다.

포함: 6열 유효성 검사 → 나이 80세 상한 → 저장된 회귀 파이프라인(현재 단일 RandomForestRegressor 단계) → 예측 cm.

제외: cm 이후 잔차 분포로 신체 참고점수를 계산하는 physical_probability, 당뇨·고혈압 Platt 보정, 또래 백분위 변환, 등수, 종합점수. 허리 회귀 출력 뒤의 별도 cm 보정은 없습니다. 기존 metadata의 통합 calibrationVersion을 cm 보정이라고 읽으면 안 됩니다.

## 열 이름과 순서

| 순서 | 열 | 형식 | 단위·규칙 |
|---|---|---|---|
| 1 | age_years | 정수값 숫자 | 만 나이 19~120. 모델에서 min(age,80). 배경은 이미 19~80으로 정리됨 |
| 2 | sex_code | 정수값 숫자 | 1=남성, 2=여성 |
| 3 | height_cm | 실수 | cm, 100~220 |
| 4 | weight_kg | 실수 | kg, 25~250 |
| 5 | leisure_aerobic_moderate_equivalent_min_week | 실수 | 분/주, 0 이상. 여가 중강도 분+2×여가 고강도 분 |
| 6 | strength_days_week | 정수값 숫자 | 0,1,2,3,4,5. 5는 5일 이상이며 세션 수가 아님 |

CSV는 UTF-8, 쉼표 구분, 헤더 포함, 인덱스 열 없음입니다. DataFrame 열 순서는 위와 같아야 합니다. CSV 정수값 열은 정수로 기록했습니다. 내부 전처리는 수치 배열로 검사하므로 1.0 같은 정수값 숫자는 허용하지만 숫자 문자열·bool·NaN·무한값은 허용하지 않습니다. 필수 입력 누락은 미산출/호출 거부이며 0 대체·평균 대치가 없습니다. 0은 실제 미활동 기록으로 유지됩니다.

점수용 주간 입력은 설문 의미에 맞게 이미 집계된 값입니다. 생년월·운동 저/중/고·강도·취침/기상 같은 앱 원래 입력을 이 표에 직접 혼합하지 마세요. 새로운 앱 사용자의 원입력은 기존 vNext 정규화 규칙을 먼저 적용해야 합니다. 근력 6·7일은 기존 앱 어댑터에서 5로 매핑한 뒤 넣습니다. cm 래퍼는 canonical 6·7을 조용히 고치지 않고 오류로 거부합니다.

임신 적격성은 숫자 6열 밖에서 확인합니다. 개발 표본은 원래 허리 태스크 적격·측정값 존재·6입력 완전 사례 코호트입니다. 결측이 있는 원본 전체 조사 대상이나 질환별 코호트로 확대하지 않았습니다.
