# vNext 시험 범위와 연령 경계 처리 방향

이번 추가 전달은 현재 사용자 요청에 따른 앱 설명 시험용 기준 정리다. 타 팀의 운영 승인이나 제품 최종 정책 합의를 새로 기록하는 문서가 아니다.

## 이번 설명 시험

기존 vNext v0.2 후보, 모델·참조·산식 해시를 고정해 사용한다. 허리둘레 SHAP은 cm 출력만 설명한다. 기존 앱 카드·종합값은 기존 응답대로 표시하되 SHAP cm 기여도를 그 점수의 가감점으로 붙이지 않는다. 배경·모델·래퍼 버전을 계산 결과와 함께 저장한다.

## 운영 전 방향

1. 현재 후보의 40·65세 경계에서 상대 위치가 크게 달라지는 문제는 미해결로 유지한다. 생일 월의 나이 근사 정책이 이 문제를 해결한 것은 아니다.
2. 시험 화면에서도 comparisonKey가 달라지면 점수 증감·건강 개선 비교를 보류하고 비교 기준이 달라졌음을 설명한다. comparisonKey는 연령대 외에 나이·가용 영역·모델·참조 변경에도 달라질 수 있다. 측정/활동 기록의 사실 비교와 점수 비교는 구분한다.
3. 운영 기본 화면에 현 후보의 또래 순위를 확정 채택하는 것은 보류한다. 경계 처리 검증이 끝나지 않은 상태에서 운영에 연결해야 한다면 해당 또래 순위·종합 변화 안내를 노출하지 않는 보수적 방안을 우선 검토한다. 이 패키지가 실제 앱 UI를 수정한 것은 아니다.
4. 연속 연령 참조 또는 인접 연령대의 부드러운 전환 등 대안을 같은 입력을 고정한 경계 스윕으로 비교한다. 성별·키/체중·활동량 여러 조합에서 점프 크기, 참조 표본 수, 해석 가능성을 점검한 뒤 팀이 채택안을 정한다. 새 참조 규칙을 채택하면 reference/formula/comparisonKey 버전과 기대 샘플을 함께 갱신한다.

이번에는 기존 산식·참조표 변경이나 연령 경계 완화 모델을 구현하지 않았다. 따라서 '운영 문제 해결 완료'로 전달하지 않는다. 실측 건강 개선이나 치료 효과를 뜻하는 표현도 사용하지 않는다.
