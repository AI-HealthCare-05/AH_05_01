# 틈튼 Android 디자인 기준

2026-09-21 `main`의 **시안 C · 미션 중심 홈**을 기준으로 합니다. 9월 17일 B안과 중간 팔레트 시안은 현재 화면을 되돌리는 근거로 사용하지 않습니다. 이 문서는 이미 반영된 화면을 설명하며 새 팔레트나 레이아웃을 제안하지 않습니다.

## 홈의 정보 순서와 상태

1. 카드 미션이 가장 큰 영역입니다. 선택 전에는 숲색 카드 뽑기 패널, 선택 후에는 현재 카드 디자인으로 메시지·행동·목표를 표시합니다.
2. 시작·이어 하기·쉬어가기는 카드 미션에 붙여 묶습니다. 다음 틈새운동 영역까지 32dp를 두어 소속을 구분합니다.
3. 완료한 카드는 홈에서 응원 패널로 바뀝니다. 서버가 저장을 확인한 틈새운동 0·1·2회에 따라 응원과 달성 이미지가 달라집니다.
4. 틈새운동은 오늘 카드 완료 후 열립니다. 운동 매트 그림과 닫힌/열린 자물쇠, 상태 글자를 함께 표시합니다. 숫자 5를 아이콘처럼 쓰지 않습니다.
5. 틈튼일보는 Pretendard 제목·구분선·삽화로 신문 느낌을 유지하고 다른 보조 영역과 모서리를 맞춥니다. 허리둘레는 흰 면에 숲색 추정값과 긴 줄자를 표시합니다.

카드 문구·목표는 실제 선택된 카드 데이터입니다. 로딩·없음·실패 상태에서 임의 값을 만들지 않습니다. 전체 사용자 흐름은 [앱 안내](../docs/APP_GUIDE.md)를 따릅니다.

## 색의 역할

| 역할 | 현재 구현 |
| --- | --- |
| 브랜드·주요 버튼·선택 전 미션 | 숲색 `#3F5D4B` |
| 본문 / 보조 본문 | `#2C2C2C` / `#666A71` |
| 앱·홈 일보·허리둘레 바탕 | 흰색 |
| 선택한 카드 종이 / 글자 / 테두리 | `#FFF8E9` / `#315342` / `#AC8E61` |
| 틈새운동 잠김 / 열림 | `#F4ECE3` / `#FFBA00` + 자물쇠와 상태 글자 |
| 저·중·고강도 | `#62683D` / `#3F5D4B` / `#684B3C` + 이름과 막대 개수 |
| 센서형 라벨 | 짙은 주황 `#9A4310`, 작은 의미 표시 |
| 오늘 / 오류 | `#FF7A1A` / `#C92A2A` |

색 원본은 [TmtnColor.kt](app/src/main/java/com/tmtn/app/ui/theme/TmtnColor.kt)와 [TmtnHomeColor.kt](app/src/main/java/com/tmtn/app/ui/theme/TmtnHomeColor.kt)입니다. 기존 카드의 종이와 잠금 상태 색을 다른 큰 배경까지 확대하지 않습니다. 캐릭터 원본의 색·형태와 투명 배경을 유지합니다.

## 글자·간격·접근성

Pretendard와 [TmtnType.kt](app/src/main/java/com/tmtn/app/ui/theme/TmtnType.kt)를 사용합니다. Android 글자는 sp, 치수는 dp입니다. 기본 제목은 32/42sp, 큰 결과는 36/44sp, 본문은 16/26sp이며 사용자 글자 크기를 반영합니다.

홈 좌우 여백은 20dp, 미션과 행동 버튼 사이 8dp, 미션 묶음과 틈새운동 사이 32dp입니다. 보조 패널은 20dp 모서리이며 같은 간격으로 모든 영역을 나열하지 않습니다. 숫자와 동작을 강조하되 설명은 본문·보조 글자색으로 읽기 순서를 만듭니다.

- 누를 수 있는 영역은 48dp 이상을 유지합니다. 닫힌 영역에는 실행 동작을 제공하지 않습니다.
- 좁은 화면·큰 글자에서 줄바꿈하거나 세로로 재배치합니다. 중요한 수치·단위·안내를 말줄임하지 않습니다.
- 달력은 실천·쉼·미완료를 채움·실선·점선으로도 구분합니다. 주간은 월요일부터 시작합니다.
- 허리둘레는 추정값임을 표시합니다. 인치는 원 cm 값에서 변환하며 실제 측정값·바지 사이즈로 설명하지 않습니다.
- 기존 누름 피드백과 시스템 동작 줄이기를 유지합니다. 운동 센서 화면은 응원·일시정지·달성 정지 이미지를 사용합니다.
- 일보의 댐은 현재 서버 단계(0~5)를 반영합니다. 과거 주의 댐 스냅샷으로 설명하지 않습니다.

## 확인 범위

현재 구현은 Android입니다. 새로운 iOS 화면이나 Figma 중간 시안을 제품에 적용된 것으로 간주하지 않습니다. [통합 검증 기록](../docs/INTEGRATION_2026-09-21.md)에 빌드·기기 확인 범위를 남겼으며, 추가 UI 변경은 실제 좁은 화면·큰 글자·오류·복귀 흐름으로 확인합니다.
