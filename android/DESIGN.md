# 틈튼 Android 디자인 기준

기준일: 2026-09-17. 사용자 승인 B안(숲색)과 파스텔 배경 제거 요청을 반영한다. 기존 흰색·먹색·Pretendard·수채화 캐릭터를 유지하며, 이전 베이지·세이지 배경 기준은 이 문서로 대체한다.

## 색의 역할

| 역할 | 기준 | 근거 |
|---|---|---|
| 브랜드·주요 버튼·선택 외곽선 | 숲색 `#3F5D4B` | 기존 브랜드 색, B안 승인 |
| 숲색 위 글자·아이콘 | 흰색 `#FFFFFF` | 대비 확보 |
| 숲색 위 보조 글자 | 무채색 `#E8E8E8` | 이번 적용값 |
| 앱·신문·허리둘레 카드 배경 | 흰색 `#FFFFFF` | 파스텔 배경 제거 요청 |
| 보조 패널·비활성 주변 면 | 무채색 `#F5F5F5` | 이번 적용값, 색조 없는 구획 |
| 본문 / 보조 본문 | `#2C2C2C` / `#666A71` | 기존 기준 유지 |
| 외곽선 / 구분선 | `#858585` / `#D9D9D9` | 이번 적용값 |
| 오늘 표시 | 주황 `#FF7A1A` | 달력의 기존 의미 유지 |
| 오류 | 빨강 `#C92A2A` | 기존 오류 의미 유지 |

큰 면에 베이지·세이지·연한 살구·연노랑을 사용하지 않는다. 삽화 안의 나무·나뭇잎·비버 색은 원본을 유지한다. 숲색을 모든 글자와 배경에 채우지 않는다. 숫자 강조·동작과 선택에 사용하고, 설명은 먹색·회색으로 읽기 순서를 만든다. 선택지는 숲색 테두리와 체크를 함께 쓰고, 하단 탭은 숲색 면·흰 아이콘·숲색 라벨로 구분한다. 날짜의 쉼·미완료는 기존 실선·점선 구분을 유지한다.

색상 원본은 `app/src/main/java/com/tmtn/app/ui/theme/TmtnColor.kt`이다. 화면마다 비슷한 연한 색을 새로 만들지 않는다.

## Typography · Spacing · Layout

Android 글자 단위는 sp, 나머지 치수는 dp. Pretendard의 기존 `TmtnType`을 재사용한다.

| 역할 | 크기 / 줄높이 | 굵기 |
|---|---|---|
| 큰 결과 값 | 36 / 44 sp | Bold |
| 화면 제목 | 28 / 36 sp | Bold |
| 카드 제목·cm 요약 | 22 / 30 sp | SemiBold |
| 틈새 운동 제목 | 18 / 26 sp | SemiBold |
| 인치 보조 값 | 18 / 28 sp | Medium |
| 본문 | 16 / 26 sp | Regular |
| 버튼 | 16 / 24 sp | Bold |
| 설명 | 14 / 20 sp | Medium |

홈 좌우 여백 20dp, 카드 사이 16dp, 보조 카드 안쪽 가로 18dp·세로 16dp, 모서리 20dp를 사용한다. 시안에서 검증한 배치를 제품에 반영했다. 추가 크기를 정할 때는 시작값임을 명시하고 실제 기기로 검증한다.

큰 글자에서는 신문 그림을 100dp에서 64dp로 줄여 링크·화살표 공간을 확보한다. 허리둘레는 값 영역을 그림 아래로 옮기고, 추정값 라벨은 필요하면 다음 줄로 흐르게 한다. 중요한 수치를 말줄임하거나 가로 스크롤에 숨기지 않는다.

## Interaction · Micro-animation · Component behavior

- 기존 누름 피드백, 시트 드래그·진입·퇴장, 시스템 동작 줄이기 대응을 유지한다. 이번 색상 변경 때문에 장식 반복 동작을 추가하지 않는다.
- 틈새 운동은 오늘 카드 완료 후 카드 전체를 눌러 진입한다. 완료 전에는 잠금 아이콘과 안내를 표시하고 클릭 동작을 제공하지 않는다.
- 추가 재료를 모두 받은 뒤에도 둘러보기는 유지한다. 실제 보상·운동 가능 여부는 기존 상태와 서버가 결정한다.
- 허리둘레는 같은 자리에서 설명을 펼치고 접는다. 확인 중에는 숫자를 만들지 않고, 오류·없음은 기존 재시도 흐름을 유지한다.
- cm 원값을 2.54로 나눈 뒤 소수 첫째 자리 HALF_UP으로 인치를 표시한다. cm를 먼저 반올림하지 않는다. 서버 API·DB·계산 모델·저장 단위는 변경하지 않는다.
- 홈·상세 모두 추정값임을 표시한다. 인치 값은 바지 표기 사이즈 추천이 아니며 기존 측정값 차이 안내와 구매 참고 설명을 함께 제공한다.

## 플랫폼 범위

이번 PR은 현재 프로젝트의 Android 앱에 적용한다. iOS 구현은 이 저장소에서 확인하지 않았고 변경하지 않았다. 향후 iOS 대응 시 동일한 역할·정보 순서를 사용하되 글자와 UI 치수는 pt로 별도 검증한다. Android의 dp/sp 수치를 iOS 확정값으로 취급하지 않는다.
