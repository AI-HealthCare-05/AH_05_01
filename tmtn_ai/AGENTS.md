# AGENTS.md — `tmtn_ai/` 모델 · 데이터

> 저장소 루트의 `AGENTS.md` 가 먼저입니다. 이 파일은 **모델·데이터 작업에만** 더해지는 규칙입니다.
> 이 디렉터리는 **사람의 건강 데이터**를 다룹니다. 아래 금지 사항은 스타일 문제가 아니라 안전 문제입니다.

## 구조

```
tmtn_ai/
├── contracts/   계약 YAML — 피처·분할·평가·감사 규격 (기준 문서)
├── configs/     실행 설정
├── src/         파이프라인 코드
├── tests/       계약·누설·재현성 테스트
├── docs/        감사 기록 · 리뷰 · 결과 리포트
└── artifacts/   산출물 (git 제외)
```

**계약(`contracts/*.yaml`)이 기준입니다.** 코드가 계약과 다르면 코드를 고칩니다.

# 하지 말 것

## 데이터 경계 — 어기면 결과를 통째로 버려야 합니다

- **개발 경로에서 예약 연도를 열어 보지 마세요.** 2022 는 temporal validation 용, 2023 은 locked test 입니다. 한 번 보면 그 연도는 더 이상 검증에 못 씁니다.
- **2023 라벨·양성 수·평균·성능 수치를 개발자에게 전달하지 마세요.** 개발자에게 가는 것은 피처 CSV · `developer_manifest.json` · `contract_snapshot.yaml` · SHA-256 뿐입니다.
- **2022 또는 2023 결과를 보고 모델·피처·임계값을 고르지 마세요.** 선택은 개발 구간(2019~2021) OOF 안에서만 합니다.
- **참여자 키가 들어간 CSV 를 커밋하지 마세요.** OOF 행 단위 결과는 `artifacts/` 에만 둡니다.
- **전처리 통계(평균·표준편차·인코딩)를 전체 데이터에 적합하지 마세요.** fold 안에서만 적합합니다. 누설입니다.
- **`do_not_split` · `do_not_train` · `do_not_materialize` 계약을 직접 수정하지 마세요.**

## 결과 해석

- **개발 OOF 결과로 "공개 게이트 통과"를 선언하지 마세요.** 공개는 `release_gate_2022` 를 실제로 돌린 뒤에만 말할 수 있습니다.
- **하위집단 성능을 전체 성능으로 갈음하지 마세요.** `sex_code` × `age_19_39`/`age_40_64`/`age_65_plus` 로 나눠서 보고, **각 칸에 표본 수 n 을 함께** 적습니다.
- **애매하면 강도·성능을 높은 쪽으로 판정하지 마세요.** 낮은 쪽으로 갑니다.
- **API 나 라이브러리가 주는 confidence 를 판정 근거로 쓰지 마세요.**

## 실행

- **기존 산출물을 덮어쓰지 마세요.** 새 버전으로 만듭니다.
- **seed 를 고정하지 않고 돌리지 마세요.** 재현이 안 되면 결과가 아닙니다.
- **`tmtn_ai/` 에서 `app/` 이나 `android/` 를 import 하지 마세요.**

# 할 것

## 결과를 남길 때는 영수증과 함께

성능 수치를 문서에 쓸 때는 **아래를 같이** 적습니다. 하나라도 빠지면 그 숫자는 나중에 못 믿습니다.

- 사용 연도와 표본 수(n)
- seed 와 fold 구성
- 계약 파일의 SHA-256
- 실행 코드의 SHA-256
- 통과한 테스트 수

기존 `docs/WAIST_OOF_DEVELOPMENT_V0_1_RECEIPT.json` 형식을 그대로 따르세요.

## 모델을 서버에 넘길 때

서버팀이 `import` 한 줄로 쓸 수 있어야 합니다.

- 전처리까지 포함한 **joblib 하나**
- `predict_xxx(dict) -> dict` **함수 하나**
- 그 함수의 **단위 테스트**
- 입력 dict 의 키·타입·단위를 적은 **한 장짜리 계약**

## 앱이 보내는 값 (현재 계약)

| 계약 필드 | 비고 |
| --- | --- |
| `age_years` | 출생연월에서 계산. 정확한 날짜는 받지 않음 |
| `sex_code` | **KNHANES 코드 그대로 1=남 2=여** |
| `height_cm` / `weight_kg` | |
| `leisure_aerobic_moderate_equivalent_min_week` | `중강도 분 + 2 × 고강도 분` |
| `strength_days_week` | 0~5. 5 = 주 5회 이상(top-code) |
| `pregnancy_status` | **모델 피처 아님.** 자격·안전 판단용 |

**허리둘레는 앱에서 받지 않습니다.** 계약상 실측값을 모델 입력으로 쓸 수 없어 항상 추정합니다.

## 테스트

계약 준수·누설 차단·재현성은 **테스트로 고정**합니다. 문서로만 적어 두지 마세요.
동일 입력 100회 반복이 같은 결과를 내는지 확인하는 테스트를 유지하세요.
