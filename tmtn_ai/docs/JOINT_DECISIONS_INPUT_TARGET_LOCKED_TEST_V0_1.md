# TMTN 입력·타깃·2023 잠금 테스트 공동 결정 v0.1

## 결정 상태

- 결정일: 2026-08-25
- 데이터·AI: 박강호, 병학
- 2023 잠금 테스트 정답 담당: 팀장 홍주
- 모델 학습: 아직 금지

## 1. 6개 모델 피처

최종 모델 피처는 다음 여섯 개로 승인한다.

1. `age_years`
2. `sex_code`
3. `height_cm`
4. `weight_kg`
5. `leisure_aerobic_moderate_equivalent_min_week`
6. `strength_days_week`

P0 유산소 입력은 주당 일수, 회당 시간, 대표 강도 한 개를 받는다. 서버는 중강도일 때 `일수 × 분`, 고강도일 때 `2 × 일수 × 분`으로 환산한다. P1 정밀 입력에서는 중강도와 고강도를 분리한다.

나이 80세 이상 top-code, KNHANES 생물학적 성별 매핑, cm/kg 단위, 근력운동 5일 이상 top-code와 자기보고 입력의 한계를 승인한다.

## 2. 임신 정책

- P0 건강 모델: 임신 체크 사용자를 제외한다.
- 챌린지 기능: 건강 모델 미지원과 별개로 안전한 서비스 경로를 제공한다.
- P1: KNHANES 임신 관련 변수·측정값·표본 수·라벨 타당성 감사를 먼저 수행한다.
- P1 감사 전에는 임신부 전용 모델의 개발 가능성을 확정 표현하지 않는다.

## 3. Task 대상자와 라벨

canonical ETL v0.1의 규칙을 그대로 승인한다.

- 허리둘레: 비임신 성인 + `waist_cm` 유효
- 당뇨 측정 이상: 비임신 성인 + 공복 8시간 이상 + 공복혈당/HbA1c 모두 유효, `glucose >= 126 OR HbA1c >= 6.5`
- 고혈압 측정 이상: 비임신 성인 + 공식 SBP/DBP 모두 유효, `SBP >= 140 OR DBP >= 90`
- 타깃 결측 대치: 금지
- 출력 의미: 미래 발병이나 임상 확진이 아닌 현재 단일 검진의 측정 이상 확률

## 4. 2023 잠금 테스트 운영

홍주님이 2023 정답키 custodian을 맡는다. 홍주님은 hn23 원자료를 보유하고 있으므로 2023 canonical 생성부터 task cohort 및 정답키 분리까지 전용 코드로 실행한다.

- 강호·병학: 코드와 계약 작성, 2019~2022 개발·검증
- 홍주: 2023 materialization, 잠금 정답 보관, 동결 예측 1회 평가
- 개발자 전달물: task별 2023 피처 파일
- 제한 저장물: task별 2023 라벨 파일과 무결성 manifest
- 금지: 라벨 분포 공개, 모델 동결 전 성능 공개, 2023 결과 기반 재튜닝
