## 1. 목적과 판정 범위

이 보고서는 KNHANES 2019~2024 원자료의 모델 관련 컬럼이 연도별로 존재하는지 확인하고, 제8기·제9기 공식 원시자료 이용지침서와 대조한 변수 의미를 데이터 계약에 반영하기 위한 문서다.

스키마 감사는 CSV 헤더, 파일 형식, 컬럼 수, 파일 해시만 확인했다. 참가자 행·값·행 수·결측률·분포·라벨 비율·기술통계는 읽어 보고서에 포함하지 않았다.

이 보고서가 확정하는 범위:

- 2019~2024 연도별 핵심 컬럼 존재 여부
- 제8기와 제9기 사이의 핵심 스키마 연속성
- 공식 코드북에서 확인한 변수 의미·기본 코드·연도별 정의 변경
- 데이터 계약에서 즉시 확정할 항목과 값 수준 감사 전까지 보류할 항목

이 보고서가 확정하지 않는 범위:

- 실제 유효 표본 수와 결측률
- 문항 skip logic의 값 수준 재현
- 혈압 기기 변경에 따른 공식 변수의 보정 적용 상태
- 측정 기반 질환 라벨의 최종 cohort와 치료자 처리
- 모델 성능, calibration 또는 공개 적합성

### 5.1 질환 설문 변수 정정

- 당뇨병 자가보고 문항은 `DE1_dg/ag/pr/pt`다.
- 고혈압 자가보고 문항은 `DI1_dg/ag/pr/pt`다.
- `DM1_*`는 관절염 계열이며 당뇨병 변수가 아니다.
- `DM4_*`는 골다공증 계열이며 당뇨병 변수가 아니다.
- `DE1_*`, `DI1_*`는 2019~2024 스키마에서 동일한 기본 문항명이 확인됐다.
- 자가보고 문항은 primary 측정 라벨이 아니라 comparator·민감도 분석용으로 제한한다.

### 5.2 성인과 나이

- 핵심 GPAQ 운동 문항과 주요 생성변수는 만 19세 이상 성인을 대상으로 한다.
- 일차 분석 cohort의 최소 나이는 만 19세로 고정한다.
- `age=80`은 80세 이상 top-coded 범주로 취급하며 실제 80세와 구분할 수 없음을 기록한다.

### 5.3 근력운동

`BE5_1`은 최근 1주일 동안 근력운동을 한 날의 범주다.

| 원코드 | 계약값 |
|---:|---|
| 1 | `0_days` |
| 2 | `1_day` |
| 3 | `2_days` |
| 4 | `3_days` |
| 5 | `4_days` |
| 6 | `5_plus_days` |
| 8 | 구조적 비해당 후보 |
| 9 | 모름·무응답 |

`6`을 주 6일로 해석하지 않는다. 주 분석에서는 순서형 범주로 유지하고, 숫자 5로 근사하는 경우 별도 민감도 분석으로 표시한다.

### 5.4 유산소 신체활동

- 공식 `pa_aerobic`은 이진 생성변수이며 빈도나 시간을 복원할 수 없다.
- 공식 산식의 원천은 `BE3_71~78`, `BE3_81~88`, `BE3_91~94` 총 20개 문항이다.
- `BE3_31~33` 걷기는 공식 `pa_aerobic` 산식과 별도 문항으로 관리한다.
- 세부 문항은 일·이동·여가 활동을 포함하므로 앱의 “운동” 문구와 의미가 자동으로 일치하지 않는다.

유산소 환산식 후보:

```text
vigorous_min_week
= 일 관련 고강도 분/주 + 여가 고강도 분/주

moderate_transport_min_week
= 일 관련 중강도 분/주 + 여가 중강도 분/주 + 이동 활동 분/주

aerobic_moderate_equivalent_min_week
= moderate_transport_min_week + (vigorous_min_week × 2)
```

제8기 PDF 50쪽과 제9기 PDF 51쪽의 공식 SAS에서 branch-aware skip logic과 동일한 150분·75분 기준을 확인했다. 여부 문항이 `아니오`이면 해당 영역을 0으로 처리할 수 있지만, 여부가 `예`인데 일수·시간이 유효하지 않으면 전체 생성 조건을 통과하지 않는다. 값 수준 감사 코드가 공식 SAS 결과를 재현하는지 테스트하기 전까지 구현 상태는 보류한다.

### 5.5 당뇨병

- `HE_glu`: 공복혈당 측정값
- `HE_fst`: 총 공복시간
- `HE_HbA1c`: HbA1c 측정값
- `HE_DM_HbA1c`: 정상·전단계·당뇨병의 공식 3범주 생성변수

`HE_DM_HbA1c`의 당뇨병 범주는 공복혈당·HbA1c뿐 아니라 의사진단·약물·인슐린 치료를 포함한다. 따라서 공식 변수 의미는 검증됐지만 측정값 기반 primary target으로 승인된 것은 아니다.

공식 `HE_DM_HbA1c` 생성 cohort는 비임신자이면서 8시간 이상 공복자다. 제8기 공식 SAS는 `HE_glu`, `HE_HbA1c`와 진단·치료 구성 변수가 모두 유효할 때 공식 복합 라벨을 생성한다.

측정값만 사용하는 primary 이진 라벨 후보:

```text
eligible
= age >= 19
  and nonpregnant
  and HE_fst >= 8
  and HE_glu is not missing
  and HE_HbA1c is not missing

positive
= HE_glu >= 126 or HE_HbA1c >= 6.5
```

Primary는 임상 진단이나 미래 발병 위험이 아니라 현재 단일 방문 측정 이상 가능성으로 확정했다. 치료 중 측정값이 정상인 대상자는 primary에서 음성으로 처리하고 공식 composite comparator에서는 질환 보유 상태를 유지한다. 공복혈당·HbA1c 중 하나만 존재하는 보조 cohort와 전단계 분석은 P0 primary 밖의 보조 분석으로 보류한다.

제9기 PDF 189쪽은 2022년 임상검사 분석기관이 이전 기관보다 HbA1c를 낮게 측정하는 경향을 기록하고, 2022년 이후 자료에 적용할 연구자용 전환식 `y = 1.034x - 0.0448`을 제공한다. 질병관리청 공식통계는 전환식을 적용하지 않고 원자료를 사용한다. 본 프로젝트는 원자료 모델과 연구자용 전환값 모델을 민감도 분석으로 비교한 뒤 한 정책을 고정해야 한다.

### 5.6 고혈압

- `HE_sbp`, `HE_dbp`: 공식 최종 혈압 후보
- `HE_sbp1/2/3`, `HE_dbp1/2/3`: 회차별 혈압
- `HE_HP`: 공식 고혈압 상태 생성변수

- 2019~2021: `3=고혈압`
- 2022~2024: `4=고혈압`

고혈압 최상위 기준은 `SBP >= 140 또는 DBP >= 90 또는 약물복용`으로 유지되지만 정상·주의·전단계 범주는 제8기와 제9기에 동일하지 않다. `HE_HP` 원코드를 그대로 이어붙이지 않는다.

측정 기반 이진 라벨 후보식:

```text
HE_sbp >= 140 or HE_dbp >= 90
```

공식 지침서에서 `HE_sbp`, `HE_dbp`가 2·3차 측정 평균임을 확인했다. 혈압계는 2019년 수은혈압계, 2020년 Greenlight300, 2021년 이후 성인은 Microlife WatchBP Office를 사용한다. 연구자용 전환식은 제공되지만 공식통계 산출에는 사용하지 않았다. 본 프로젝트는 원자료 모델과 연구자용 전환값 모델의 연도별 안정성을 비교한 뒤 한 정책을 고정하며, 전환 여부와 버전을 기록한다. 이미 변환한 값에 전환식을 중복 적용하지 않는다.

## 6. 모델 입력 비교 계약

```text
F0 = age + sex + height + weight
F1 = F0 + pa_aerobic + strength_days_week
F2-total = F0 + 전체 신체활동 환산 분/주 + strength_days_week
F2-leisure = F0 + 여가 유산소 환산 분/주 + strength_days_week
```

- F0는 운동 입력이 없거나 온보딩을 건너뛴 사용자의 fallback 후보로 유지한다.
- 앱은 여가 운동의 일수·회당 시간·대표 강도를 받아 `F2-leisure`와 정렬한다.
- `F2-total`은 직장·이동·여가를 포함한 연구 비교용으로만 사용한다.
- F1·F2가 연도별·성별·연령별로 안정적인 개선을 보일 때만 6입력 모델을 주 모델로 채택한다.
- `pa_aerobic`에서 시간·빈도를 역추정하지 않는다.

질환 모델 파이프라인은 입력 피처 세트와 구분해 `D0`(선택 F 세트), `D1`(D0 + OOF 추정 허리둘레), `D2`(D1 + 향후 승인 서브모델)로 명명한다.
