# KNHANES 2019~2022 canonical ETL 최종 검토

## 1. 결론

canonical ETL v0.1-r2는 2019~2022 집계 기술 검증을 통과했다.

- 행 수 전부 보존
- ID 결측·중복 없음
- 성별·임신 상태 모순 없음
- 기존 측정 조화 감사와 P0·당뇨·고혈압 코호트 일치
- eligibility 밖 라벨 생성 없음
- 모델 입력 allowlist와 금지목록 중복 없음
- canonical 행·참여자 ID·train/test 파일 미생성
- 모델 학습·성능평가 미수행

현재 상태는 `기술 집계 확인 통과, 박강호·병학 공동 승인 대기`다. 공동 승인 전까지 `do_not_train: true`를 유지한다.

## 2. r1에서 발견한 문제와 r2 수정

r1에서는 공복시간 후보 범위 `0~48시간`의 상한을 넘는 보호 억제 소수 사례를 결측으로 바꾸었다. 그 결과 2020년 당뇨 측정 eligible이 기존 측정 조화 감사보다 작아졌다.

후보 유효범위는 아직 자동 제외 기준이 아니라 감사용 플래그라는 기존 원칙에 따라 r2에서 다음처럼 수정했다.

- 후보 범위 초과: 원수치 보존 + `below_guard` 또는 `above_guard` 기록
- 숫자 변환 실패·비유한값·원천 결측: canonical 결측 + 사유 기록
- 범위 초과값의 클리핑·자동 대치·행 삭제: 금지
- 후보 범위를 hard validity 규칙으로 승격하는 결정: 공동 검토 후 별도 확정

r2에서 2020년 당뇨 측정 eligible은 기존 기준값으로 복원됐다.

## 4. 교차검증 결과

2019~2022 각 연도에 대해 다음 항목이 모두 일치했다.

1. canonical 감사와 측정 조화 감사의 원천파일 SHA-256
2. P0 비임신 성인 코호트 수
3. 당뇨 측정 eligible 수
4. 고혈압 측정 eligible 수
5. 당뇨·고혈압 양성 수

추가 안전 점검 결과는 다음과 같다.

- 입력/출력 행 수 일치: 전 연도 통과
- ID 결측·중복: 전 연도 0
- 성별·임신 조합 모순: 전 연도 0
- 라벨의 eligibility 밖 생성: 전 연도 0
- 모델 입력 allowlist/금지목록 중복: 없음
- 2023·2024 값 접근: 없음

## 6. 공동 승인 시 확인할 결정

- 후보 유효범위는 현 단계에서 플래그 전용이며 자동 제외하지 않는다.
- 후보 범위 초과값을 학습에 사용할지는 train 데이터의 분포 검토와 임상 검토 후 hard validity 계약에서 확정한다.
- F0, F1, F2-leisure는 서로 다른 모델 후보군으로 유지하며 결측 운동값을 0으로 대체하지 않는다.
- HbA1c·혈압의 공식 원측정값은 primary, 변환값은 sensitivity 분석으로 유지한다.
- 2023년은 잠금 내부 테스트, 2024년은 현재 모델 개발에서 금지한다.

## 7. 다음 단계

공동 승인 후 다음 작업은 canonical dataset 생성·분할을 바로 실행하는 것이 아니라, 먼저 분할 스크립트를 현재 연도 역할과 canonical 계약에 맞게 개정하는 것이다.

1. 개발: 2019~2021
2. 시간 검증: 2022
3. 잠금 내부 테스트: 2023
4. 금지: 2024

분할 코드 검증과 접근권한 경계를 확정한 뒤 별도의 깨끗한 로컬 환경에서 canonical dataset과 분할 산출물을 생성한다.
