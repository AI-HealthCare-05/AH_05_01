## 1. 검토 결론

ver3는 공식 comparator 라벨, 2024년 개봉 상태, 운동 피처의 이진·연속 대안, 학습 금지 원칙을 정확히 반영했다. 충돌하던 primary 라벨, 피처·파이프라인 명칭, 검증 연도 범위는 아래 5개 결정에 따라 `data_contract_v0_2.yaml`에 반영했다. 값 수준 감사와 공동 계약 승인이 끝나기 전까지 `do_not_train: true`는 유지한다.

## 3. 사실관계 정정·보완

### 3.1 Primary 후보

ver3의 당뇨·고혈압 primary 후보는 진단·복약을 포함하므로 “측정값 기반 primary”가 아니라 “질환 상태 라벨”이다. 현재 계약은 다음을 구분한다.

- primary 후보: 공복혈당·HbA1c 또는 SBP·DBP의 측정값 기반 라벨
- comparator: 진단·복약이 포함된 `HE_DM_HbA1c`, `HE_HP`

고혈압 comparator에는 의사진단 자체가 포함되지 않고 혈압 측정값과 약물복용이 포함된다. 의사진단까지 넣는 라벨은 공식 comparator와도 다른 별도 질환 상태 라벨이 된다.

### 3.2 공식 SAS 내부명과 배포 컬럼명

- 공식 SAS 계산 과정의 `HE_DM_hb`는 배포 데이터의 `HE_DM_HbA1c`에 대응한다.
- 공식 SAS 계산 과정의 `HE_hp`는 배포 데이터의 `HE_HP`에 대응한다.

공식 지침서의 변수표·정의·생성 SAS와 6개년 실제 스키마를 대조해 확인했으므로 별도 미결정 항목으로 두지 않는다.

### 3.3 공식 당뇨 comparator cohort

공식 생성변수는 비임신·8시간 이상 공복 조건을 사용한다. 제8기 공식 SAS는 공복혈당·HbA1c와 진단·치료 구성 변수가 유효한 cohort에서 생성한다. 따라서 단순히 네 조건을 OR로 연결하는 것만으로 공식 comparator를 완전히 재현할 수 없다.

### 3.4 HbA1c 연도 조화

제9기 지침서는 2022년 이후 HbA1c에 연구자용 전환식 `y = 1.034x - 0.0448`을 제공한다. 공식통계는 원자료를 사용하므로 원자료 모델과 전환값 모델을 비교한 뒤 정책을 고정해야 한다.

### 3.5 혈압계 변경

2019년 수은혈압계, 2020년 Greenlight300, 2021년 이후 성인은 Microlife WatchBP Office를 사용한다. `HE_sbp`, `HE_dbp`는 2·3차 평균이지만 연도 비교를 위한 연구자용 전환식 적용 여부는 별도 민감도 분석이 필요하다.

### 3.6 운동 SAS

제8기·제9기 공식 SAS의 branch-aware skip logic과 150분·75분 기준이 확인됐다. 남은 일은 공식 SAS를 코드로 구현하고 생성 `pa_aerobic`과 행 수준 일치도를 검증하는 것이다.

### 3.7 2016~2018 스키마 B

2016~2018 포함안은 현재 범위에서 제외한다. 프로젝트는 HbA1c와 6개년 공통성을 이유로 2019~2024를 사용하기로 했고, 2024년도 이미 독립 holdout이 아니다. 2016~2018을 추가해도 새로운 최종 holdout이 생기지 않는다.

## 4. F 피처 세트·D 질환 파이프라인 명칭 확정

현재 계약의 M0·M1·M2는 운동 입력 가용성 비교를 의미하지만 ver3는 허리둘레와 운동 피처가 단계적으로 추가되는 질환 모델 파이프라인을 의미한다. 같은 이름을 두 의미로 사용하면 실험 결과와 API 계약이 혼동된다.

확정 명칭:

```text
입력 피처 세트
F0 = 나이 + 성별 + 키 + 몸무게
F1 = F0 + pa_aerobic + 근력운동 일수
F2-total = F0 + 전체 신체활동 환산 분/주 + 근력운동 일수
F2-leisure = F0 + 여가 운동 환산 분/주 + 근력운동 일수

질환 모델 파이프라인
D0 = 선택한 F 세트만 사용
D1 = D0 + OOF 추정 허리둘레
D2 = D1 + 추후 승인된 다른 서브모델 출력
```

BMI는 키·몸무게로 서버 재계산하는 파생값이며 독립 앱 입력으로 세지 않는다.

## 5. 확정 검증 구조

2019~2023 안에서 다음 구조를 적용한다.

```text
내부 튜닝: 2019~2021에서 반복·층화 CV
시간 검증: 2022
잠금 내부 테스트: 2023
개봉 시간 평가: 2024, 진단용이며 튜닝 금지
최종 공개 평가: 향후 신규 연도 또는 외부 데이터
```

랜덤 8:2는 시간 검증을 대체하지 않고 개발 비교 결과로 함께 보고한다. 모델·전처리·결측·보정 선택은 2023 잠금 테스트 전에 고정한다.

## 6. 확정 결정

### 결정 1. Primary가 예측할 대상 — A 확정

현재 측정 이상을 primary로 유지하고, 진단·복약을 포함한 질환 보유 상태는 comparator·민감도 분석으로 둔다. 치료 중이더라도 현재 측정값이 기준 미만이면 측정 이상 primary에서는 음성이다.

### 결정 2. 임신자 처리 — A 확정

P0 일반 성인 모델에서는 임신자를 허리둘레·당뇨·고혈압 모델 cohort에서 모두 제외하고 별도 모델을 제공하지 않는다.

### 결정 3. 앱의 유산소 입력 의미 — A 확정

앱에는 여가 목적 유산소운동의 주당 일수와 평균 분을 질문해 `일수 × 평균 분 = 분/주` 한 값으로 환산하고 `F2-leisure`와 정렬한다. 직장·이동 활동은 P0 앱 입력에 포함하지 않으며 `F2-total`은 연구 비교용으로만 둔다.

### 결정 4. 피처 세트와 질환 파이프라인 명칭 — A 확정

`F0/F1/F2`와 `D0/D1/D2` 분리를 채택한다.

### 결정 5. 검증 구조 — A 확정

2019~2021 내부 개발, 2022 시간 검증, 2023 잠금 내부 테스트, 2024 개봉 진단 평가 구조를 채택한다. 랜덤 8:2는 2019~2021 개발 자료 안에서만 보조 비교로 유지한다.
