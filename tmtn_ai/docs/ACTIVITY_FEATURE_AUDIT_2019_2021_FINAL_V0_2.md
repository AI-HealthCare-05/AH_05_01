# KNHANES 운동 피처 원자료 확인 최종 판정 v0.2

작성일: 2026-08-24  
상태: 통과 — 모델 학습은 계속 금지  
공유 대상: 데이터·AI 담당, 기획·QA 참고

## 1. 결론

2019~2021 KNHANES 개발 자료에서 운동 피처 전처리 계약의 원자료 확인 게이트를 통과했다.

- 공식 `pa_aerobic` 재현 불일치: 연도별 0건
- 공식 `pa_aerobic` 재현 일치율: 연도별 100%
- 운동 관련 22개 확인 컬럼의 예상 밖 코드: 0건
- 5개 활동 영역별 계산 가능성 확인 완료
- 원자료 SHA-256은 기존 값 감사에 사용한 파일과 동일
- 참가자 행·ID 출력 없음
- 모델 학습·튜닝·성능평가 없음
- 2022·2023 미사용, 2024 미접근

따라서 `pa_aerobic` 공식 재현식과 여가 유산소 중강도환산분 파생 코드는 2019~2021 전처리에 사용할 수 있다. 이 판정은 모델 학습 허가가 아니며 `do_not_train: true`를 유지한다.

## 2. 공식 생성변수 재현 결과

| 연도 | 전체 행 | 비교 가능 | 불일치 | 일치율 |
|---:|---:|---:|---:|---:|
| 2019 | 8,110 | 5,918 | 0 | 100% |
| 2020 | 7,359 | 5,398 | 0 | 100% |
| 2021 | 7,090 | 5,316 | 0 | 100% |

공식 `pa_aerobic`은 일·이동·여가 활동을 합산한 지표다. 앱의 여가 운동 입력과 같은 개념으로 사용하거나, 이 이진값에서 빈도·시간을 역산해서는 안 된다.

## 3. 앱 정렬 여가 유산소 피처

모델의 1차 운동 피처 후보는 다음 산식을 유지한다.

```text
여가 유산소 중강도환산분/주
= 여가 중강도 운동분/주
+ 2 × 여가 고강도 운동분/주
```

| 연도 | 계산 가능률 | 결측률 | 중앙값 | 75백분위 | 99백분위 |
|---:|---:|---:|---:|---:|---:|
| 2019 | 73.08% | 26.92% | 0분 | 60분 | 840분 |
| 2020 | 73.50% | 26.50% | 0분 | 60분 | 840분 |
| 2021 | 75.13% | 24.87% | 0분 | 60분 | 840분 |

결측률이 약 25~27%이므로 이후 canonical ETL에서 결측을 0으로 바꾸면 안 된다. F0 선택형 입력 fallback과 train-only 결측 처리 정책을 별도로 비교해야 한다.

## 4. 근력운동 피처

`BE5_1` 예상 밖 코드는 세 연도 모두 0건이며 다음 매핑을 유지한다.

| 원시코드 | 모델값 |
|---:|---:|
| 1 | 0일 |
| 2 | 1일 |
| 3 | 2일 |
| 4 | 3일 |
| 5 | 4일 |
| 6 | 5일 이상(top-coded 5) |
| 8·9·결측 | 결측 |

원자료에 선택적 공식 `pa_muscle` 컬럼이 없어 공식 생성변수와 직접 일치도 비교는 하지 못했다. 근력운동 계약은 공식 코드북의 `BE5_1` 정의, 값 도메인 확인, 합성 단위 테스트를 근거로 확정한다.

## 6. 남은 결정과 다음 단계

1. 기획·QA와 앱 운동 질문의 대표 강도 설명 및 현실적인 회당 시간 상한을 확정한다.
2. 운동 피처 결측을 포함한 2019~2021 canonical ETL 계약을 작성한다.
3. 당뇨병 HbA1c 연도 조화와 혈압 측정기기 조화 정책을 먼저 확정한다.
4. 연도 역할을 반영한 분할 코드를 개정한다.
5. 데이터 계약에서 `do_not_train`이 명시적으로 해제되기 전에는 학습하지 않는다.

## 7. 팀 공유 시 강조할 사항

- 공식 `pa_aerobic`과 앱 여가운동 피처는 서로 대체하지 않는다.
- 결측은 운동 0회가 아니다.
- F2-leisure가 현재 6개 입력 모델의 1차 후보지만 F0·F1·F2 비교 전에는 최종 모델 피처로 확정하지 않는다.
- 이번 통과는 전처리 산식 확인이지 모델 성능 또는 임상 타당성 통과가 아니다.
