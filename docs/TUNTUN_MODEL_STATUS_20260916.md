## 동결 모델과 확정 정책

N6 허리 W2·당뇨 D0·고혈압 D0 유지, 근육량·N9는 제품 미사용이다. 이번 변경에서 건강 모델과 보정기를 교체하지 않았다.

- 기준 manifest SHA-256: `bdca54917705cde75fc2d1b275c49a91ebfef05f56f45472d29e4b97ba77c2e9`
- 추론 소스 SHA-256: `c3efa5a029020390873beee0fd486c64bd293561ad26cd81c35ba095c162c61d`
- 전체 신체10·당뇨20·고혈압20·생활습관50, 생활습관 내 가입 초기20·실천80을 적용한다. 건강 성분은 건강 방향의 반올림 전 peerPercentile이다.
- 초기 습관 배점은 저강도20·중고강도50·근력일수30이며 포화 기준은 각각150분·중강도환산150분·2일이다. 초기값은 확인된 가입 설문으로 고정한다.
- 신규 사용자의 확인된 빈 원장만 실천0으로 시작한다. 미확인·조회 실패는 null이며 가용 성분만 재가중하지 않는다.
- 모든 additional 시간 가산은 실제 활동시간 확인 전까지 보류한다. 경과시간을 실측시간으로 간주하지 않는다. 기본 운동 카드와 보상 처리는 별도다.

## 구현과 검증 상태

`feature/tuntun-peer-vnext`의 `40b9f31`에서 초기 계산기·스냅샷·전환 스크립트·명시적 쉼 연결을 확인했다. 이전 문서의 초기 정책 pending·쉼 미연결 설명을 최신 상태로 갱신했다. 이번 보완은 쉼 조회 실패를 unavailable/null에 포함하고 날짜별 상태 변경을 ledger_revision에 반영한다. 관련 회귀29건 및 변경 파일 린트·포맷 통과. DB·EC2·APK 종단 검증을 대신하지 않는다.

전체 테스트는 현 환경의 AI 의존성과 동결 브릿지 import 경로 문제로 수집 중단됐고 기존 다른 파일의 린트·포맷 문제도 남아 있다. 전체 CI 통과를 뜻하지 않는다.

가입 원본의 시간 근접성 판정, 실제 문항 의미와 입력 정의 버전, pending 전환과 backfill 동시 실행, API·홈·일보 표시 일치는 운영 인수에서 확인한다. ledger_revision은 조회 내용 해시이며 원자적 DB snapshot이나 경쟁 제어를 대체하지 않는다.

담당자 수신 다른 연도 평가의 상세 수치는 데이터 관리 경계에 따라 모델 담당 로컬 보고서에서 확인한다. 원자료·개인별 예측·새 모델 바이너리는 추가하지 않는다. 이번 PR은 운영 배포나 과거 DB 일괄 전환을 실행하지 않는다.
