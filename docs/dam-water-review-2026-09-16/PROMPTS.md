# 이미지 제작 기록

제작일: 2026-09-16. 도구: Codex 내장 `image_gen.imagegen`. 모든 결과는 기존 앱 그림을 참조한 편집으로 만들었습니다. 아래는 최종 제작 지시의 요약이며 원본 요청 전문의 전사본은 아닙니다. 파일별 SHA-256은 `assets.json`에 있습니다.

## 공통 캐릭터 지시

기존 틈튼이와 동일한 캐릭터를 유지한다. 부드러운 수채화, 낮은 채도의 살구색 둥근 몸, 작은 귀, 갈색 눈과 코, 크림색 주둥이와 두 앞니, 은은한 분홍 볼, 세이지색 잎 모자와 사선 가방, 갈색 타원 꼬리의 격자무늬. 과장된 광택이나 두꺼운 검은 외곽선, 짙은 주황색, 길어진 몸을 넣지 않는다. 소품만 장면에 맞게 바꾼다. 배경은 깨끗하고 따뜻한 흰 종이색으로 둔다.

## 결과별 지시

### `dam_water_repair_sheet.png`

- 참조: 기존 `figma_dam_repair_sheet.png`.
- 같은 댐의 여섯 단계를 3열×2행, 1536×1024 한 장에 만든다. 카메라·기둥·모래·바위·새싹 위치와 수채화 질감을 고정한다.
- 0단계는 중앙 빈틈으로 넓게 흘러 모래에 퍼지는 물, 이후 단계마다 나무와 재료가 빈틈을 메워 앞쪽 물길을 줄인다. 마지막에는 물이 댐 뒤에 있고 앞쪽 모래는 마른다.
- 오른쪽 바깥의 폭포·옆으로 새는 별도 물길은 제거한다. 캐릭터·단계 숫자·제목·테두리는 넣지 않는다.
- 생성 결과 식별자: `exec-f0bdacf8-2ab7-4e94-ba44-4870d4d33eab`.

## 검수와 사용

원본·생성 결과·앱에 들어간 화면을 눈으로 비교했습니다. 최종 PNG는 RGB이며 따뜻한 흰 종이 배경을 포함합니다. 배경 체크무늬가 그림 안에 그려진 중간 결과는 사용하지 않았습니다. 프로그램으로 캐릭터를 합성하거나 다시 그리지 않았으며, 댐의 여섯 장면은 UI의 잘라 보기로 표시합니다.

교체 전 그림은 Git 이력에 남습니다. 새 에셋은 저장소에 포함하므로 담당자가 이미지 생성 도구나 API를 다시 실행할 필요가 없습니다.
