# 약관·개인정보·동의 항목 분리

2026-09-16 · 운영자 **문홍주** · 개인정보·서비스 문의 **salaam4040@naver.com**

이 폴더는 앱의 항목별 안내를 분리한 **운영자 검토본**이다. 공개용 법률 문서 확정본이 아니다. 화면 분리와 문구 적용은 완료했지만, 보유 기간·실제 위탁/제공/국외 이전·시행일을 확인하기 전에는 최종 약관으로 배포하지 않는다. 기존의 임의 시행일을 제거했다.

만 14세 이상 확인은 기존 필수 체크 항목으로 유지한다. 기존 필수/선택 정책 자체를 이번 UI 변경에서 재설계하지 않았다. 건강정보 전체를 필수로 받는 정책의 적정성은 운영자와 개인정보 담당자가 별도 검토할 항목이다.

‘알림 수집 동의’라는 하나의 항목으로 개인정보 수집과 알림 수신을 합치지 않는다. 이번 `NOTIFICATION`은 카드 등 서비스 알림 선택이며 광고성 정보 수신 동의가 아니다. 광고·마케팅을 추가한다면 별도 목적·문서·철회 처리가 필요하다. 측정 중 상태 알림과 Android 알림 권한도 별개다.

## 화면 동작

- 각 ‘보기’는 해당 문서만 연다. 읽거나 닫아도 체크 상태는 바뀌지 않는다.
- 개인정보 처리방침과 수집·이용 동의는 서로 다른 본문이다.
- ‘선택 항목을 포함해 모두 동의’는 선택 범위를 문구에 명시한다. 선택 항목 미동의로 가입을 막지 않는다.
- 다른 문서를 열면 처음부터 읽는다. 내 정보에서 돌아가기는 열었던 화면으로 복귀한다.
- 문서 본문은 스크롤 가능하며, 제목·본문·보조 문구를 기존 Pretendard 계층으로 나눈다.

## 백엔드 영향

**이번 변경으로 필요한 서버 코드/DB 마이그레이션은 없다.** API, DTO, purpose 문자열, 기존 저장 버전 `v1`은 유지했다. `PRIVACY_POLICY`라는 기존 이름은 호환을 위해 수집·이용 동의의 저장 코드로 계속 사용한다. 처리방침 ‘읽기’용 신규 동의 기록을 만들지 않는다.

다만 **확정 문서를 실제 공개할 때**는 목적별 문서 버전, 시행일, 기존 동의자에 대한 고지/재동의 필요 여부를 팀에서 결정해야 한다. 변경된 전문을 기존 `v1`과 동일한 확정 문서라고 취급하지 않는다. 현재 서버가 새 버전을 받아 저장·조회하는지 통합 시험하고, 검토본을 확정본으로 교체한 뒤 해당 버전을 연결한다. 실제 저장·철회 이력은 이번 오프라인 단위 테스트로 검증한 범위가 아니다.
