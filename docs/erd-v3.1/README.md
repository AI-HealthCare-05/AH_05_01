# TMTN ERD v3.1 — 검증 결과와 보정안

2026-08-29 · 기준 문서 `TMTN_ERD_v3.0.md` (114 테이블) · Figma **v5 (107화면)** · 저장소 `AH_05_01`

---

## 한 줄 결론

**설계는 튼튼합니다. 문제는 설계가 아니라 저장소입니다.**

v3.0 ERD(114 테이블)와 ORM 모델(114 테이블)은 **한 곳도 어긋나지 않았습니다.**
그런데 실제 저장소에는 테이블이 **`users` 하나뿐**이고, 그 `users` 마저 ERD와 다릅니다.

| 층 | 상태 |
|---|---|
| ERD 문서 (DDL) | 114 테이블 · 949 컬럼 · FK 161 · CHECK 45 · UNIQUE 59 · 뷰 5 ✅ |
| ORM 모델 7개 파일 | 114 테이블 — DDL과 **완전 일치** ✅ |
| **실제 저장소 `app/models/`** | **`users.py` 1개** ❌ |
| **실제 마이그레이션** | `users`, `aerich` **2개 테이블** ❌ |
| 앱 `missions.json` | 200장 있음. 다만 **용어 체계가 ERD와 다름** ⚠️ |

즉 "ERD를 다시 짜야 하는" 상황이 아니라, **113개 테이블이 아직 저장소에 안 들어간** 상황입니다.
