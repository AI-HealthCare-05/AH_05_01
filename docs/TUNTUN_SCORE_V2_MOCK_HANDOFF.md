# 튼튼지수 V2 Mock 앱 연동

## 상태

- 화면·API 통합 확인용 Mock이다.
- production 모델 배포나 의료적 해석을 승인하지 않는다.
- 기존 `GET /api/v1/tuntun-score` 계약은 변경하지 않는다.
- 신규 `GET /api/v1/tuntun-score/v2`만 Android 참고 탭에서 사용한다.
- DB migration이나 점수 이력 저장은 이번 범위에 없다.

## 화면 구조

```
튼튼지수 종합점수
├─ 신체
├─ 당뇨
├─ 고혈압
└─ 생활습관
   ├─ 유산소
   └─ 근력
```

각 영역은 `score`, `available`, `bandLabel`, `guidance`를 제공한다. 입력이 없는
영역은 `null`이고 종합점수에서 제외한다. 종합점수는 available인 영역만 같은
비중으로 평균한다. 0점은 측정된 실제 값이며 결측과 다르다.

## Mock 계산 범위

- 신체·당뇨·고혈압: 연령·성별·키·몸무게가 모두 있으면 UI 확인용 고정 Mock 값.
- 생활습관 유산소: `(중강도 분 + 2 × 고강도 분) / 150 × 100`, 최대 100점.
- 생활습관 근력: `주당 일수 / 2 × 100`, 최대 100점.
- 생활습관: available인 유산소·근력 점수의 평균.
- 미션: 현재 완료 일수는 응답에 기록하지만 점수에는 반영하지 않는다. 활동 환산,
  충분한 센서 coverage, 설문→미션 전환 기준이 승인된 후 별도 연결한다.

## 안전·노출 규칙

- `isMock`은 항상 `true`다.
- 질환 확률, 복부비만 내부 확률, participant ID, OOF seed/fold는 응답하지 않는다.
- 화면에 비진단적 참고 점수 안내와 Mock 표시를 노출한다.
- 65세 이상이면 별도 불확실성 안내를 노출한다.

## 다음 교체 지점

production refit·패키징이 끝나면 `TuntunScoreService.get_score_v2()`의 고정 건강영역
Mock 값만 실제 추론 결과로 교체한다. DTO와 Android 화면 계약은 유지한다.
