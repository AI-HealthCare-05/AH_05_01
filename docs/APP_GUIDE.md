# 현재 앱과 사용자 흐름

기준: 2026-09-21 `main`, Android 1.0.3. 실제 하단 탭은 **홈 · 기록 · 일보 · 댐 · 내 정보**입니다.

## 처음 시작할 때

로그인·회원가입 → 항목별 동의 → 기본·신체·운동 정보 → 생활시간·권한 안내 → 첫 댐과 첫 재료 → 오늘의 카드로 이어집니다. 첫 재료 지급·복구 상태는 서버에서 관리하여 재진입 때 같은 단계를 복원합니다. 첫 선물을 받는 일을 오늘 카드나 틈새운동 완료로 계산하지 않습니다.

Google 로그인은 서버 OAuth와 Android 웹 클라이언트 ID·서명 설정이 있어야 동작합니다. 화면 구현 여부와 실제 인증 설정 여부는 구분합니다.

## 홈 · 시안 C

상단 카드 미션을 가장 크게 두고 틈새운동·틈튼일보·허리둘레를 아래에 배치합니다. 시작·쉬어가기 버튼은 카드와 가깝게 묶고, 틈새운동과는 간격을 둡니다.

| 상태 | 홈의 중심과 다음 행동 |
| --- | --- |
| 카드 선택 전 | 큰 미션 영역에서 오늘의 카드 고르기 |
| 카드 선택 후 | 선택한 카드의 크림색 이중 테두리·문구·목표를 표시하고 행동 시작 |
| 실천 중·일시정지 | 기존 세션으로 이어 하기. 틈새운동 복귀 배너도 진행 상태 유지 |
| 오늘 카드 완료 | 카드 전문 대신 틈튼이 응원. 완료 카드 다시보기는 보조 링크 |
| 틈새운동 1회 완료 | 한 번 더 실천한 것을 칭찬하고 선택권을 남김 |
| 틈새운동 2회 완료 | 달성 이미지와 “오늘은 충분히 멋졌어.”, 내 댐으로 연결 |
| 쉼·포기 | 해당 상태를 명시. 미완료를 자동으로 쉼 처리하지 않음 |

완료 응원은 **서버에 저장이 확인된 해당 날짜의 완료 횟수**를 사용합니다. 센서 목표 도달·저장 대기·저장 실패는 완료로 세지 않습니다. 완료 카드 다시보기와 뒤로가기에도 같은 현재 카드 컴포넌트를 사용합니다.

카드 문구·행동·목표는 데이터로 구성합니다. 변경 시 [서버 콘텐츠 안내](../app/scripts/data/README.md)를 확인합니다. 과거 장식 프레임과 얇은 전용 폰트를 다시 적용하지 않습니다.

## 틈새운동과 센서

- 오늘 카드가 완료되어야 열리며 닫힌/열린 자물쇠로 상태를 표시합니다.
- 서버 카탈로그에서 앱이 계정·날짜별 **최대 5개**를 골라 유지합니다. 같은 날 재진입해도 목록이 계속 바뀌지 않으며, 후보가 적으면 있는 항목만 보여 줍니다.
- 하루 추가 보상 한도는 **2회**이며 서버가 관리합니다. 목록 개수와 보상 가능 횟수는 다른 값입니다.
- 센서형 표시, 인식 대기·인식 중·일시정지, 진행량과 목표를 구분합니다.
- 캐릭터는 응원·일시정지·달성 **정지 이미지**를 사용합니다. 폐기된 걷기 GIF·분리된 팔다리 모션을 쓰지 않습니다. 앱 시작의 런치 GIF는 별개입니다.
- 위치 권한·위치 서비스·기압 센서 지원 여부를 확인합니다. 측정 불가를 목표 달성으로 처리하지 않습니다.
- 저장 실패 시 같은 완료 요청을 재시도하여 중복 보상을 막습니다. 돌아가기만으로 진행 중 세션을 지우거나 새로 시작하지 않습니다.

관련 구현: `CardHomeState`, `HomeCompletionPanel`, `DailyExerciseSelection`, `ExerciseMissionScreens`, `app/services/exercise_mission_service.py`.

## 틈튼일보와 기록

주간면은 **월요일~일요일** 고정이고, 일간면은 선택 날짜의 기록을 보여 줍니다. 지난주 기록이 있으면 실천 비교를 제공하고, 개인 XAI 결과는 실제 저장된 최근 8주 이력을 사용합니다. 없는 주를 0점으로 채우지 않으며 비교 가능한 버전끼리만 변화를 보여 줍니다.

일보의 댐은 companion API의 **현재 단계와 누적 재료**입니다. 과거 주간 기록을 읽더라도 그 그림을 당시 댐의 스냅샷이라고 표현하지 않습니다. 조회 실패 때 임의의 단계 그림으로 대신하지 않습니다.

일보의 일반 읽을거리는 검토된 목록에서 일간·주간 호에 맞춰 선택합니다. 개인 XAI와의 차이는 [XAI 안내](XAI.md)를 확인합니다.

기록 탭에서는 실천·명시적 쉼·미완료를 구분합니다. 쉼은 사용자가 직접 선택하며 주 2회 제한을 서버가 관리합니다.

## 허리둘레·댐·내 정보

- 허리둘레: 서버 추정값을 cm와 inch로 표시합니다. 홈 줄자는 값의 위치를 보여 주는 표현이며 센서 측정이나 건강 등급이 아닙니다.
- 댐: 재료 5종과 단계 0~5, 다음 단계까지 남은 재료, 완료 카드첩을 확인합니다.
- 내 정보: 기본·신체·운동 정보, 생활시간·알림, 동의·권한과 계정 설정을 관리합니다. 출생 정보는 연·월 단위입니다.

색·글자·여백은 [디자인 기준](../android/DESIGN.md)과 `ui/theme/`를 따릅니다. 큰 글자·TalkBack·동작 줄이기 대응을 유지합니다. 약관·동의 본문은 [검토본 목록](legal/README.md)에서 관리합니다.
