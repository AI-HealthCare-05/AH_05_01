### 자주 쓰는 부품

| 하고 싶은 것 | 쓰는 것 |

| 안내 상자 | `NoteBox(title = …, body = …)` · 경고는 `tone = NoteTone.Warning` |
| 주 버튼 | `TmtnFilledButton("문구") { }` |
| 보조 버튼 | `TmtnTonalButton` · `TmtnOutlinedButton` · `TmtnQuietButton` |
