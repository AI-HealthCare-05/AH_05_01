# 캐릭터 에셋 검토

2026-09-16 · imagegen 스킬 / 내장 imagegen 도구 사용.

- 실제 확인: beaver_walking.png는 이전 굵은 외곽선·선명한 가방 캐릭터.
- 현재 앱 반영: beaver_wave.png (기존 승인된 수채화 틈튼이, 실제 RGBA alpha 0~255).
- 적용: CardHomeScreen.kt의 ExtraExerciseHomeEntry, 기본 Fit, 72/84dp.
- 기존 beaver_walking.png 파일은 다른 작업과의 충돌을 피하도록 삭제하지 않았으나 main 소스 참조는 남지 않았다.

## 생성 이력

1. 참조 beaver_wave.png에서 동일 캐릭터의 작은 걷기 포즈 생성.
   출력: exec-817ffabe-a594-4df0-83b2-aba581d230d3.png
2. 첫 결과의 배경 체크무늬 제거·실제 alpha 요청.
   출력: exec-fa5558ee-1d51-4bf4-b969-dbfd575f0967.png

두 결과 모두 PNG이지만 RGB 모드이며 체크무늬가 실제 픽셀로 포함됐다. 파일 모드와 이미지를 직접 검사했다. **두 출력 모두 앱에 미채택**. 생성된 파일을 투명 에셋으로 잘못 전달하지 않는다. 새로운 포즈가 꼭 필요하다면 실제 alpha 출력이 검증된 파일로 다시 교체한다.

1차 프롬프트는 현재 캐릭터의 주황 수채화 질감, 연한 세이지 잎과 가방, 두 앞니, 꼬리, 외곽 여백을 고정하고 걷는 포즈만 요청했다. 2차 프롬프트는 캐릭터를 그대로 두고 배경을 alpha=0으로 바꾸도록 요청했다. 적용 파일은 생성 결과가 아닌 기존 캐릭터다.
