# 데모 표시 걷어내기 — 서버·모델 붙일 때 보는 문서

> 대상: 백엔드(장혁수) · 모델(박강호)
> 마지막 확인 2026-08-30 · 갤럭시 S23+ 실기기

지금 앱에는 "아직 데모다" 라고 알리는 문구가 몇 군데 있습니다.
전부 코드에 **마커**를 달아 두었으니 한 번에 찾을 수 있습니다.

```bash
grep -rn "\[DEMO" android/app/src/main/java/
```

마커는 **두 종류**이고, 처리 방법이 서로 다릅니다. 섞지 마세요.

---

## `[DEMO]` — 지워야 하는 것

서버가 붙으면 **사실과 달라지는** 문장입니다. 코드에서 직접 지워야 합니다.

| 위치 | 무엇 | 언제 지우나 |
|---|---|---|
| `ui/auth/LoginScreen.kt` | "아직 데모 단계예요 / 서버 없이 이 기기 안에서만 동작해요" | 로그인 API 연동되는 즉시 |
| `ui/tabs/TabScreens.kt` | "데모 데이터 초기화" 버튼 | 서버가 계정 데이터를 갖게 되면 |

두 곳뿐입니다. 안 지우면 **거짓말이 됩니다** — 서버로 값을 보내면서
"다른 곳으로 보내지 않습니다" 라고 써 있게 되니까요.

---

## `[DEMO-MODEL]` — 지우면 안 되는 것

모델이 아직 임시 구현이라 뜨는 안내입니다.
**코드를 건드릴 필요가 없습니다.** 진짜 모델을 넣고 플래그만 내리면 저절로 사라집니다.

```kotlin
// domain/ml/ModelSlot.kt
val isPlaceholder: Boolean   // 이걸 false 로 두면 끝
```

| 위치 | 무엇이 사라지나 |
|---|---|
| `ui/home/HomeScreen.kt` | "샘플 값이에요 — …" |
| `ui/mission/MissionIntroScreen.kt` | "아직 샘플 측정이에요" |
| `ui/mission/ModelMissionScreen.kt` | "샘플 측정 중이에요" |
| `ui/mission/MissionCompleteScreen.kt` | "이 기록은 샘플 측정값이에요" |
| `ui/tabs/TabScreens.kt` | 연결된 모델 목록의 "샘플" → 실제 버전 문자열 |

모델 교체는 `domain/ml/ModelRegistry.kt` 한 파일에서 합니다.
세 슬롯(허리둘레·행동인식·틈튼지수)은 각각 따로 내릴 수 있습니다 —
하나만 진짜가 되면 그 화면만 안내가 사라집니다.

---

## 절대 지우면 안 되는 것 (데모와 무관)

`ui/tabs/TabScreens.kt` 틈튼지수 탭의 이 문구는 **데모 표시가 아닙니다.**

> 비진단용 참고 정보입니다 — 진료를 대신하지 않습니다…

의료기기가 아니라는 선을 긋는 안전 문구입니다.
`CLAUDE.md` 에 "이 문구를 빼지 마세요" 로 못 박혀 있습니다.
데모 문구를 정리하다가 **같이 지우지 않도록** 주의하세요.

---

## 이미 지운 것 (2026-08-30)

사용자가 굳이 몰라도 되는 안내라 판단해 뺐습니다. 되살릴 필요 없습니다.

- 내 정보 탭 — "주민등록번호와 전체 생년월일은 받지 않습니다. 위치는…"
- 온보딩 1단계 — "여기 적은 값은 계정에만 저장되고 외부 제공에 쓰지 않습니다."

다만 **왜 묻는지** 설명하는 문구는 남겼습니다
("정확한 날짜는 받지 않습니다. 연·월만 있으면 충분해요" 등).
이건 빼면 "왜 생년월일을 묻지?" 하는 의심이 생깁니다.
