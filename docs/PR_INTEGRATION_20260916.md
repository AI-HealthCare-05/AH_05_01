## 리뷰 보완

1. Google 신규 가입은 필수 동의 4종과 문서 버전 v1을 검증한다. 계정·선택한 동의를 한 트랜잭션에 저장하고 동의 저장 실패 시 계정도 롤백한다.
2. Google 전용 계정은 같은 Google 계정의 최근 발급 토큰으로 계정 삭제와 최초 비밀번호 설정을 할 수 있다. 다른 계정, 발급 후 5분 초과, 미래·누락 발급 시각은 거절한다.
3. 허리둘레 모델의 최초 자동 승인만 생성한다. 관리자의 기존 비활성 상태와 승인 주체를 덮어쓰지 않는다.
4. 또래 점수는 디버그 앱에서 내부 검토용으로 유지한다. 릴리스 앱은 기본 비활성이며 모델·브릿지 배포 승인을 받은 뒤에만 `-PTMTN_PEER_SCORE_APPROVED=true`로 빌드한다. 비활성 상태에서는 점수 요청을 보내지 않고 기록·카드·일보 흐름을 유지한다.
5. 순위 표시는 기존 수정의 서버 `rankDisplay` 사용을 보존했다. 빈 DB의 컬럼 존재 확인 마이그레이션도 기존 수정을 보존했다.

## API·호환성

- `POST /api/v1/auth/google`: 신규 가입 확정 요청에 `consents: [{purpose, document_version}]`를 추가한다. 필수 동의를 보내지 않는 구버전 Google 신규 가입은 422로 거절되므로 서버 반영 후 새 앱을 배포한다. 기존 계정 로그인은 유지한다.
- `GET /api/v1/users/me`: `requires_google_reauth`를 추가한다.
- 비밀번호 변경·계정 삭제 요청은 기존 비밀번호 방식 외에 `google_id_token`을 지원한다.
- #18의 점수 조회 실패는 null 점수와 `ledger_state`로 구분한다. null을 0점으로 바꾸지 않는다.
- 이번 리뷰 보완은 DB 스키마를 추가 변경하지 않는다. #15에 포함된 기존 마이그레이션은 배포 전 별도로 적용해야 한다.

## 로컬 검증

- Android 디버그 빌드, 단위 테스트 85개, Android 테스트 코드 컴파일, Lint 통과.

- Ruff 검사·서식 검사 통과.
- Galaxy S23+ / Android 16에서 320dp·글자 1.8배 Google 재인증 화면 검사 2개 통과. 외부 Google 인증과 실제 계정 삭제는 실행하지 않았다.
- 기기 검사에서 패키지 분리 설정이 적용되지 않아 테스트 도구가 `com.tmtn.app`을 설치·제거했다. 기존 설치 상태를 사전에 확인하지 못해 사용자에게 알리고 추가 설치를 중단했다.
- 전체 mypy는 기존 외부 모델 패키지의 중복 `d0_inference` 모듈 오류로 중단됐다. 전체 타입 검사 통과를 의미하지 않는다.
- MySQL을 사용하는 기존 API 검사와 AI 환경 검사는 GitHub CI 결과를 확인한다.

## 배포·롤백

서버 API·기존 마이그레이션 반영 후 새 Android 앱을 배포한다. 이번 develop 통합은 운영 배포·모델 공개 승인이 아니다. 실제 Google 설정·서명, 서버 전체 연동, 실외 GPS와 모델 성능 검증은 별도다.

문제가 생기면 통합 커밋을 되돌린다. 이미 적용한 DB 마이그레이션은 데이터 상태를 확인한 후 별도로 롤백하며 자동으로 삭제하지 않는다.
