# XAI와 틈튼일보

## 서로 다른 세 가지 내용

| 표시 | 데이터와 의미 |
| --- | --- |
| 실천 기사·주간 비교 | 사용자가 완료·저장한 카드와 실천 기록으로 구성 |
| 개인 계산 이야기 | 실제 모델의 입력별 SHAP 기여도. 해당 입력·모델·기준일에 연결된 설명 |
| 일반 읽을거리 | 출처·내용 해시·승인·연령·기한을 확인한 기사 목록에서 선택 |

일반 기사를 XAI나 LLM이 요청마다 새로 작성하지 않습니다. 개인 SHAP는 질환별 내부 참고점수에 대한 기여도이며 또래 백분위·실천 보상·인과 효과를 분해한 값이 아닙니다. 의료적 판단이나 치료 효과를 뜻하지 않습니다.

## 연결과 표시 조건

API는 `app/services/personal_xai_service.py`, 별도 추론 서비스는 `model_service/`, 원본은 `model_assets/xai/payload/`입니다. [EC2 배포](DEPLOYMENT.md)에서 두 Python 환경과 공통 토큰을 준비합니다.

- 로그인과 `HEALTH_REFERENCE_ANALYSIS` 동의가 필요합니다.
- 모델이 요구하는 신체·운동 정보와 지원 범위를 확인합니다.
- 과거 근력 빈도의 단위가 확인되지 않으면 주간 일수로 가정하지 않습니다. 앱에서 운동 정보를 다시 저장하여 확정합니다.
- 입력·모델·설명 기준이 맞는 결과만 표시합니다. 입력이 달라졌는데 이전 설명을 붙이지 않습니다.
- 미션 완료 횟수를 개인 모델의 실제 운동 입력으로 임의 환산하지 않습니다.
- 현재 모델·읽을거리 설정은 **팀 내부 검토·시연용**입니다. 공개 운영 게이트를 승인으로 위조하지 않습니다.

| API | 역할 |
| --- | --- |
| `GET /api/v1/tuntun-score/personal` | `pending` → 실제 계산의 `ready` 결과 |
| `GET /api/v1/tuntun-score/personal/history` | 회원별 최근 8주 저장 결과 |
| `GET /api/v1/tuntun-score/editorial` | 승인 조건을 통과한 읽을거리 |

## 주간 이력

월요일부터 일요일까지 한 주로 묶고 실제 `ready` 결과만 저장합니다. 같은 주에는 최신 정상 결과를 보관합니다. 과거 실천 기록이 있더라도 개인 XAI를 저장한 적이 없으면 과거 점수를 복원하거나 0점으로 만들지 않습니다. 모델·기준 버전이 달라 비교할 수 없는 두 점수를 변화량으로 표시하지 않습니다. 동의가 철회된 회원에게 개인 설명과 이력을 표시하지 않습니다.

## 읽을거리 관리

원천은 [일보 데이터 안내](../app/data/journal/README.md)와 같은 폴더의 `knowledge.json`, `sources.json`, `approvals.json`, `internal_approvals.json`입니다. 승인 ID·내용 해시·출처 버전·사용 범위·유효기간을 함께 검사합니다. 문장 자체의 `review_status` 한 칸을 바꾸는 것으로 공개되지 않습니다.

내부 시연 승인 40건은 `ENV=local/dev`에서 사용하며 공개 운영 승인을 대신하지 않습니다. 일간 호는 1편, 주간 호는 서로 다른 주제의 2편을 선택하고 같은 호에서는 순서를 유지합니다. 조회 시점에 조건을 통과한 글이 부족하면 임의의 글을 만들지 않습니다.

## 상태별 조치

| 상태·사유 | 확인할 내용 |
| --- | --- |
| `not_configured` | API의 XAI URL·토큰과 Compose override |
| `consent_required` | 해당 회원의 분석 동의 |
| `input_required` / `strength_days_unconfirmed` | 신체·운동 입력과 근력 일수 단위 |
| `pending` / `busy` | 계산 대기와 앱의 재조회 흐름 |
| `calculation_failed` | 모델 로그, 두 Python 환경, 원본 SHA-256 |
| `release_review_required` | 공개 운영 게이트. 내부 시연 승인으로 해제하지 않음 |

## 원본과 검증 근거

`python3 tools/check_xai_assets.py`는 원본 124개의 바이트를 검사합니다. `.gitattributes`와 포맷 도구 제외 설정을 유지하고 모델 묶음의 줄바꿈을 바꾸지 않습니다. 누락을 숨기려고 manifest를 다시 만들지 않습니다.

[실제 통합 검사](INTEGRATION_2026-09-21.md)는 Linux SHAP→인증 API→합성 주간 저장소 연결을 확인했습니다. 현재 EC2 회원 DB로 수행한 검증은 아닙니다. 모델 선택과 실험 수치·그림은 [모델 개발 보고서](model-development-20260917/REPORT.md)에 보존합니다. 연구 후보인 근육량·N9를 현재 제품 적용 모델로 설명하지 않습니다.

과거 가입 입력의 시간 근접성만으로 원본 설문 의미를 확정하지 않습니다. 초기 습관 pending 전환·backfill 동시 실행·기존 입력 단위와 실제 서버 표시의 일치는 DB 담당자의 인수 항목입니다. 현재 프로필로 과거 가입값을 덮어쓰거나, 누락 건강 성분을 0으로 채워 점수를 만들지 않습니다.
