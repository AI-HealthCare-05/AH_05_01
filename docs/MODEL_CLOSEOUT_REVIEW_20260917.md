# 모델 개발 마무리·연결 검토 — 2026-09-17

## 현재 기준

확인 기준 브랜치 `feature/tuntun-peer-vnext`, 커밋 `40b9f31`. 기존 PR18은 병합됐고 초기 습관 계산기·스냅샷·전환 스크립트·명시적 쉼 연결이 추가됐다. 코드 존재와 운영 배포 완료를 구분한다. 본 변경은 동결 건강 모델 파일이나 보정기를 교체하지 않는다.

모델 담당 최종 결정은 N6 W2 허리, 당뇨 D0 RF+Platt, 고혈압 D0 RF+Platt 유지다. 근육량과 N9는 연구 보존·제품 미사용이다. 개발 서술과 미채택 실험은 [종합 보고서](model-development-20260917/REPORT.md)에 통합했다. 그 보고서는 과거 선택의 설명이며 연구 후보의 배포 승인이 아니다.

초기 습관은 저강도20·중고강도50·근력일수30, 포화150분/중강도환산150분/2일이다. 가입 초기점수 고정, 생활습관 내부 초기20:실천80, 전체 신체10:당뇨20:고혈압20:생활습관50을 유지한다. 결측을0으로 대치하거나 가용 건강 성분만 재가중하지 않는다. additional의 경과시간 가산은 계속 보류한다.

## 이번 수정과 검증

1. 쉼 조회가 추가된 뒤 정책 테스트4건이 실제 DB 경로에 진입하던 문제를 저장소 mock 보완으로 수정했다. 실천 상태 구성은 별도 함수로 분리하되 운동 우선/명시적 쉼/무기록 의미를 유지했다.
2. 쉼 조회 실패를 정상 무기록이나0점으로 처리하지 않고 기존 원장 조회 실패와 동일한 unavailable/null 응답에 포함했다.
3. ledger_revision에 날짜별 실천 상태를 포함해 동일 운동량이어도 쉼 변경이 유지 보너스와 점수 버전에 반영되도록 했다. 이 해시는 조회 내용 식별이며 원자적 DB snapshot 보장이 아니다.
4. 정책·기존 병합 회귀29건 통과, 변경 서비스·테스트 린트/포맷 통과. 건강 추론식·초기점수식·실천 산식 자체는 변경하지 않았다.

전체 테스트 시도는 별도 AI 의존성 미설치 및 브릿지 `src` import 경로로 수집 중단됐다. 기존 전체 린트에는 다른 미션 서비스·초기 산식 복잡도 경고와 포맷 차이가 있다. 이번 범위 검증을 전체 저장소 통과라고 보고하지 않는다.

## 운영 인수에서 확인할 항목

| 항목 | 현재 코드에서 확인한 상태 | 남은 확인 |
|---|---|---|
| 가입 원본 | 최초 신체/운동 행의 시간 차이≤1시간으로 확인 | 시간 근접성만으로 가입 시점·완성 설문·문항 의미를 보증할 수 없음. 온보딩 제출/동의/리비전과 대응 확인 |
| 운동 정의 | 계산 시 정의 버전을 상수로 전달 | 실제 문항의 여가 범위·주간 합계·근력 일수와 계약 일치 확인 |
| 기존 pending | 조회는 기존 스냅샷 반환, 별도 backfill 제공 | 신규 설문 완료 후 pending 고착 없는지, 기존 원본 확인 후 전환되는지 |
| backfill | 감사 행과 갱신을 트랜잭션으로 묶음 | 동시 실행 시 row lock/상태 재검사와 기존 input_revision 대조, 복구 절차 |
| 쉼 | 명시적 is_rest_day 연결 | 실천 없는 날과 confirmed_rest의 실제 UX 의미, additional만 완료한 날 처리 |
| 점수 표시 | 초기 계산 및 표시 정책 반영 커밋 존재 | 실제 API·홈·일보·재실행 일치, 구버전 점수 차이를 실천 성과로 표시하지 않음 |

위 확인을 대신하려고 과거 가입값을 현재 프로필로 소급하거나 raw 모델 확률·cm를 합산에 넣지 않는다. 운영 DB 전환과 배포는 담당자가 검토 후 진행하며 이 PR이 직접 실행하지 않는다.
