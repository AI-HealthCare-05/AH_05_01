## 1. 색을 전부 갈아끼웁니다 · 가장 먼저 · 30분

v4의 초록 팔레트는 **폐기**되었습니다. 파일 하나만 바꾸면 앱 전체가 따라옵니다.

`designsystem/TmtnColor.kt` 를 이 패키지의 것으로 덮어쓰세요.

| 쓰임 | v4 (버림) | v5 (지금) |
|---|---|---|
| 화면 바탕 | `#F4F5F3` | **`#FFFFFF`** |
| 카드 바탕 | `#FFFFFF` | **`#F7F4EE`** |

| 주 버튼 | `#0C3B2E` | **`#16181C`** |

| 보상 | `#FFBA00` | `#FF7A1A` / 배경 `#FFB400` |

**색 규칙 (이게 제일 중요합니다)**

> 주황(`Secondary`)은 **"오늘"에만** 씁니다.
> 완료·실천·주 버튼은 전부 먹색(`Primary`)입니다.

v4에서 완료 표시가 주황 동그라미였는데, 주황이 너무 많아 눈이 아프다는 피드백으로
**완료는 먹색, 주황은 오늘 하나**로 정리했습니다. 이 규칙을 깨면 화면이 다시 시끄러워집니다.

재료 5종 색도 바뀌었습니다 — 나뭇가지 `#FF7A1A` · 받침돌 `#E03131` · 물길 `#1C6DD0` · 다짐흙 `#FFB400` · 새잎 `#2F9E44`.

## 3. 쉼(휴식) 기능이 새로 생겼습니다 · 반나절 · 신규 화면 2장

v4에는 없던 흐름입니다. **연속 기록을 지켜 주는 장치**라 사용자 이탈에 직접 영향을 줍니다.

### 규칙
- 사용자가 **직접** "오늘은 쉬어가기"를 눌러야 쉼으로 기록됩니다.
- 쉼으로 표시한 날은 **연속 기록이 끊기지 않습니다.**
- **한 주에 두 번까지** 쉴 수 있습니다.
- 아무것도 안 하고 지나간 날은 **미완료**이고, 이때는 연속 기록이 끊깁니다.

### 화면
| 화면 | 하는 일 |
|---|---|
| `B16 · 홈 · 쉬어가기 확인` **[신규]** | 홈에서 쉼 버튼 → 바텀시트로 확인. 남은 쉼 횟수 표시 |
| `B17 · 홈 · 오늘은 쉼` **[신규]** | 쉼 확정 후 홈. "연속 기록 14일째 · 그대로 이어져요" 를 보여줌 |
| `D06 · 쉼으로 표시` | 달력에서 지난 날짜를 쉼으로 바꿀 때 |
| `D05 · 연속 기록` | 쉼 규칙 설명 |

### 쉼 버튼이 있는 곳 (3군데)
- `B01` 홈 · 카드 뽑기 전
- `B01b` 홈 · 미션 진행 중
- `B06` 카드 공개 화면
- (+ `C01` 미션 실행 화면 하단도 "오늘은 쉬어가기")

### 서버에 필요한 것
`challenge_events` 에 `REST` 종류의 이벤트가 필요합니다. 주당 2회 제한을 **서버에서** 세야
기기를 바꿔도 숫자가 맞습니다. 혁수님께 이 문단을 그대로 전달하세요.

## 4. 기록 탭이 전면 개편됐습니다 · 반나절

### 4-1. 월간 / 주간 탭
`D01`(월간)과 `D02`(주간)를 오갈 방법이 없었습니다. 앱바 아래 **`월간 | 주간` 탭**을 넣었습니다.
Material3 기본 탭 + 아래 2dp 인디케이터. 선택된 쪽만 먹색 Bold.

### 4-2. 달력이 월요일 시작
일요일 시작 → **월요일 시작**. 요일 헤더도 `월 화 수 목 금 토 일`.
`WeekFields` 대신 `DayOfWeek.MONDAY` 기준으로 계산하세요.

### 4-3. 날짜 상태가 4가지 (이게 핵심)

| 상태 | 표시 | 숫자색 |
|---|---|---|
| **실천** | 먹색 꽉 찬 원 34dp | 흰색 |
| **쉼** | 먹색 **실선** 테두리 1.5dp + 바탕 `#EFEAE0` | 먹색 |
| **미완료** | 회색 `#B8B2A6` **점선** 테두리 1.5dp (`dash 2.5 / gap 2.5`) | `#666A71` |
| **오늘** | 주황 실선 테두리 2dp | 먹색 |
| 예정 | 아무것도 없음 | `#807D76` |
| 지난달·다음달 | 아무것도 없음 | `#B8B2A6` |

> **실선 = 쉼(내가 고른 것), 점선 = 미완료(빠진 것).**
> 색만이 아니라 선 종류가 달라서 흑백으로 봐도 구분됩니다. 이 대비를 없애지 마세요.

Compose 에서 점선은 `PathEffect.dashPathEffect(floatArrayOf(2.5f, 2.5f))` 로 그립니다.

범례(`실천 · 쉼 · 미완료 · 오늘`)는 달력 칸과 **똑같은 모양**의 12dp 스와치를 씁니다.

### 4-4. 8주 히트맵 삭제
`D01` 아래 "최근 8주" 막대그래프는 **없앴습니다** (위 달력과 같은 데이터를 두 번 보여줬음).
대신 **연속 기록 카드** — `연속 기록 / 규칙 보기 › / 14 일째 / 쉼으로 표시한 날은 기록을 끊지 않아요 / 가장 오래 이어간 기록 21일`.

### 4-5. 주간 리포트(D02)
- 주간 스트립도 **월요일 시작**, 이번 주 월~일. 오늘은 주황 링, 앞으로 올 날은 흐리게.
- 스트립 아래 **범례 추가**.
- 앱바의 "월간" 버튼은 탭과 겹쳐서 없앴습니다.

## 5. 글자 · 그대로입니다 (확인만)

7단계 그대로입니다. `Type.kt` 를 덮어쓰면 됩니다.

| 이름 | 크기/행간 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| Display | 40/50 | Black | 오늘의 핵심 수치. **화면당 하나만** |
| Headline | 32/42 | Black | 화면 제목 |
| Title | 24/32 | Bold | 카드·섹션 제목 |
| Body large | 19/28 | Medium | 핵심 설명 |
| Body | 16/26 | Regular | 기본 본문·입력 |
| Label | 14/20 | Bold | 버튼·탭·라벨 |
| Caption | 14/20 | Medium | 날짜·단위. **핵심 정보에 쓰지 말 것** |

- Noto Sans KR 에 SemiBold(600)가 **없습니다.** Bold(700)로 대체했습니다.
- 숫자 나오는 곳은 `fontFeatureSettings = "tnum"` 을 거세요. 타이머·점수가 흔들리지 않습니다.
- v3 스타일(`_v3 (보존)/...`)은 옛날 페이지용이라 **쓰지 마세요.**
